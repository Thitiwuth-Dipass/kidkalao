# คิดค่าเหล้า: คู่มือติดตั้งเป็น LINE MINI App

แอปนี้เปิดในแอป LINE ได้โดยตรง ทุกคนในกลุ่มเปิดบิลเดียวกัน ช่วยกันใส่รายการ และกด "โอนแล้ว" เองได้ ระบบรู้ว่าใครเป็นใครจากบัญชี LINE และส่งสรุปเข้ากลุ่มเป็นการ์ดพร้อมปุ่ม "เปิดบิล"

ใช้บริการฟรี 3 อย่าง ทำบนคอมพิวเตอร์ ใช้เวลาประมาณ 30–45 นาที

| บริการ | ใช้ทำอะไร |
|---|---|
| Firebase (ของ Google) | เก็บข้อมูลบิล ให้ทุกคนเห็นตรงกันแบบสด |
| GitHub Pages | วางไฟล์เว็บไว้บนอินเทอร์เน็ต |
| LINE Developers | ทำให้เปิดในแอป LINE ได้ ใช้ชื่อและรูปจาก LINE |

ทำตามลำดับ 1 → 2 → 3 เพราะขั้นที่ 3 ต้องใช้ลิงก์จากขั้นที่ 2

---

## ขั้นที่ 1: Firebase (ที่เก็บข้อมูล)

1. เข้า https://console.firebase.google.com แล้วเข้าสู่ระบบด้วยบัญชี Google
2. กด **Create a project** ตั้งชื่อ เช่น `kidkalao` จะปิด Google Analytics ก็ได้ แล้วกดสร้าง
3. เมนูซ้าย **Build → Firestore Database → Create database**
   - ถ้ามีให้เลือก edition ให้เลือก **Standard**
   - Location เลือกภูมิภาคที่ใกล้ไทย เช่น **asia-southeast1 (Singapore)** (เลือกแล้วเปลี่ยนไม่ได้)
   - เลือก **Start in production mode** แล้วกดสร้าง
4. ในหน้า Firestore ไปที่แท็บ **Rules** ลบข้อความเดิมทั้งหมด แล้ววางเนื้อหาจากไฟล์ `firestore.rules` ในโฟลเดอร์นี้ กด **Publish**
5. เมนูซ้าย **Build → Authentication → Get started** แล้วไปที่แท็บ **Sign-in method** เลือก **Anonymous** กดเปิด (Enable) แล้ว Save
   - แอปใช้การเข้าสู่ระบบแบบไม่ระบุตัวตนนี้เพื่อให้ผ่านกฎความปลอดภัย ผู้ใช้ไม่ต้องทำอะไรเพิ่ม
6. กดรูปฟันเฟือง **Project settings** → แท็บ General → เลื่อนลงไปที่ **Your apps** → กดไอคอน **`</>`** (Web)
   - ตั้งชื่อแอป ไม่ต้องติ๊ก Firebase Hosting แล้วกด Register app
   - จะเห็นโค้ด `const firebaseConfig = { apiKey: "...", ... };`
   - คัดลอกเฉพาะก้อน `{ ... }` ไปวางแทนก้อน `FIREBASE_CONFIG` ในไฟล์ `config.js`

ตัวอย่างหลังวาง:

```js
export const FIREBASE_CONFIG = {
  apiKey: "AIzaSy...",
  authDomain: "kidkalao.firebaseapp.com",
  projectId: "kidkalao",
  storageBucket: "kidkalao.firebasestorage.app",
  messagingSenderId: "1234567890",
  appId: "1:1234567890:web:abc123"
};
```

ค่าเหล่านี้ไม่ใช่รหัสลับ วางไว้ในไฟล์ที่เปิดเผยได้ ความปลอดภัยของข้อมูลมาจากกฎในขั้นที่ 4

## ขั้นที่ 2: GitHub Pages (วางเว็บ)

1. เปิดไฟล์ `privacy.html` ด้วยโปรแกรมแก้ข้อความ แก้คำว่า `ใส่อีเมลของคุณตรงนี้` เป็นอีเมลของคุณ แล้วบันทึก
2. สมัครหรือเข้าสู่ระบบ https://github.com
3. กด **New repository** ตั้งชื่อ `kidkalao` เลือก **Public** แล้วกด Create repository
4. ในหน้าที่ขึ้นมา กดลิงก์ **uploading an existing file** แล้วลากไฟล์ทั้งหมดในโฟลเดอร์นี้ลงไป
   (`index.html`, `app.js`, `calc.js`, `store.js`, `config.js`, `privacy.html`, `firestore.rules`, `README.md`) แล้วกด **Commit changes**
5. ไปที่ **Settings → Pages**
   - Source เลือก **Deploy from a branch**
   - Branch เลือก **main** และโฟลเดอร์ **/ (root)** แล้วกด Save
6. รอ 1–2 นาที แล้วรีเฟรชหน้า Settings → Pages จะเห็นลิงก์ประมาณ
   `https://ชื่อผู้ใช้.github.io/kidkalao/`
7. กลับไปที่ Firebase → **Authentication → Settings → Authorized domains → Add domain** ใส่ `ชื่อผู้ใช้.github.io`
8. ลองเปิดลิงก์จากข้อ 6 ในเบราว์เซอร์คอมพิวเตอร์
   - ถ้าใส่ค่า Firebase ถูก จะไม่มีแถบ "โหมดทดลอง"
   - ยังมีแถบ "ยังไม่ได้ใส่ LIFF ID" ได้ เพราะยังไม่ได้ทำขั้นที่ 3
   - ลองกดสร้างบิลดูได้ ถ้าสร้างได้แปลว่า Firebase ใช้ได้แล้ว

## ขั้นที่ 3: LINE MINI App

1. เข้า https://developers.line.biz/console/ แล้วเข้าสู่ระบบด้วยบัญชี LINE
2. กด **Create a new provider** ตั้งชื่อ เช่น ชื่อของคุณ
3. ใน provider นั้น กด **Create a new channel → LINE MINI App** แล้วกรอก
   - Region: **Thailand**
   - Channel name: `คิดค่าเหล้า` และใส่คำอธิบายสั้นๆ
   - Email: อีเมลของคุณ
   - Privacy policy URL: `https://ชื่อผู้ใช้.github.io/kidkalao/privacy.html`
   - ยอมรับข้อตกลง แล้วกด Create
4. เข้า channel ที่สร้าง ไปที่แท็บ **Web app settings**
   - ในส่วน **Developing** ใส่ **Endpoint URL** เป็นลิงก์จากขั้นที่ 2 ข้อ 6 ให้ตรงทุกตัวอักษร รวม `/` ตัวท้ายด้วย
   - ถ้ามีตัวเลือก **Share target picker** ให้เปิด
   - กดบันทึก ระหว่างที่ยังไม่ผ่านการตรวจ ค่าในส่วน Developing จะถูกใช้กับส่วน Published ให้อัตโนมัติ
5. คัดลอก **LIFF ID ของส่วน Published** (หน้าตาประมาณ `2001234567-AbCdEfGh`)
6. กลับไปที่ GitHub เปิดไฟล์ `config.js` → กดไอคอนดินสอ (Edit) → แก้บรรทัด
   ```js
   export const LIFF_ID = '2001234567-AbCdEfGh';
   ```
   แล้วกด **Commit changes**
7. รอ 2–10 นาที ให้ GitHub อัปเดตเว็บ

## ขั้นที่ 4: เริ่มใช้งาน

1. ส่งลิงก์นี้ให้ตัวเองในแชท LINE (แชท Keep memo ก็ได้): `https://miniapp.line.me/LIFF_ID_ของคุณ`
2. แตะลิงก์ในแอป LINE → กดอนุญาตให้เข้าถึงโปรไฟล์ → จะเห็นรูปและชื่อของคุณมุมขวาบน
3. สร้างบิล แล้วกด **ชวนเพื่อนในกลุ่ม LINE** เลือกกลุ่มที่จะส่ง เพื่อนจะได้การ์ดพร้อมปุ่ม "เปิดบิล"
4. เพื่อนที่เปิดบิลครั้งแรกจะเห็นกล่อง "คุณคือใครในบิลนี้" ให้แตะชื่อตัวเอง หรือกดเพิ่มตัวเองเข้าบิล
5. ทุกคนช่วยกันใส่รายการได้ พอจบงานกด **ส่งสรุปเข้ากลุ่ม LINE**
6. ใครโอนเสร็จแล้วกด **โอนแล้ว** ทุกคนจะเห็นทันที ถ้ากดผิดกด "เลิกทำ" หรือ "ยกเลิก" ในรายการที่โอนแล้ว

## เมื่อเจอปัญหา

| อาการ | สาเหตุที่พบบ่อย |
|---|---|
| ขึ้น "เชื่อมต่อ LINE ไม่สำเร็จ" | LIFF ID ใน `config.js` ผิด หรือ Endpoint URL ไม่ตรงกับลิงก์เว็บ (ลืม `/` ท้าย) |
| ขึ้น "เชื่อมต่อ Firebase ไม่สำเร็จ" | ยังไม่เปิด Anonymous ในขั้นที่ 1 ข้อ 5, วางค่า config ไม่ครบ หรือยังไม่เพิ่ม Authorized domain |
| สร้างบิลไม่ได้ หรือขึ้น "บันทึกไม่สำเร็จ" | ยังไม่ได้กด Publish กฎในขั้นที่ 1 ข้อ 4 |
| กด "ส่งเข้ากลุ่ม" แล้วแอปคัดลอกข้อความแทน | ยังไม่ได้เปิด Share target picker หรือเปิดแอปนอก LINE ให้วางข้อความที่คัดลอกในแชทแทนได้ |
| เพื่อนเปิดลิงก์แล้วขึ้น "ไม่พบบิลนี้" | ยังอยู่ในโหมดทดลอง (มีแถบสีส้มด้านบน) ให้ใส่ค่า Firebase ให้ครบ |
| แก้ไฟล์แล้วหน้าเว็บยังเหมือนเดิม | GitHub ยังอัปเดตไม่เสร็จ รอสักครู่แล้วปิดเปิดใหม่ |

## ค่าใช้จ่าย

- **Firebase:** แพ็กเกจฟรี (Spark) พอสำหรับกลุ่มเพื่อนใช้กันสบายๆ ถ้าใช้เกินโควตาฟรี ระบบจะหยุดรับข้อมูลชั่วคราว ไม่ตัดเงินเอง เพราะไม่ได้ผูกบัตร
- **GitHub Pages:** ฟรีสำหรับ repository แบบ Public
- **LINE MINI App:** สร้างและใช้แบบยังไม่ผ่านการตรวจได้ทันที ไม่มีค่าธรรมเนียมในเอกสารของ LINE

## เรื่องความปลอดภัยที่ควรรู้

- ใครมีลิงก์บิลจะเปิดดูและแก้ไขบิลนั้นได้ ส่งลิงก์ให้เฉพาะคนในกลุ่ม
- ไม่มีใครดูรายการบิลทั้งหมดในระบบได้ และลบบิลทิ้งไม่ได้ (กำหนดไว้ใน `firestore.rules`)
- เบอร์พร้อมเพย์ที่ใส่ทุกคนในบิลเห็น ถ้าไม่อยากให้เห็นเลขบัตรประชาชน ให้ใช้เบอร์มือถือแทน

## ไฟล์ในโฟลเดอร์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าจอทั้งหมด |
| `app.js` | การทำงานของหน้าจอ เชื่อม LINE และส่งข้อความเข้ากลุ่ม |
| `calc.js` | สูตรหารเงิน จับคู่การโอน และ QR พร้อมเพย์ |
| `store.js` | อ่านและเขียนข้อมูลบิล (Firebase หรือโหมดทดลอง) |
| `config.js` | **ไฟล์เดียวที่ต้องแก้** ใส่ LIFF ID และค่า Firebase |
| `privacy.html` | นโยบายความเป็นส่วนตัว ใช้ตอนสร้าง channel |
| `firestore.rules` | กฎความปลอดภัยของฐานข้อมูล วางใน Firebase |

ถ้ายังไม่ได้ใส่ค่าใน `config.js` แอปจะเปิดใน "โหมดทดลอง" ใช้งานได้ครบในเครื่องเดียว เหมาะไว้ลองก่อนตั้งค่าจริง
